### 2. DETAILED REPOSITORY INVESTIGATION

#### 2.1 BRAG (`latent-spaces/brag`)
- **Core Philosophy:** "You built it. Now brag." High-density, impactful visual storytelling designed to hold attention in the first 5 seconds.
- **Key Discovered Assets/Skills:**
  - `skills/brag/` and `skills/brag-slim/`: Defines crisp animation pacing rules, 20-30 second high-impact structural arcs, and kinetic title cards.
  - Native Antigravity discovery: Auto-detects from `.agents/skills/brag/`.
- **Applicability to Project Gauss:**
  - Informs **Scene 01 (The Hook)**: Eliminates sluggish academic intros. Sets up immediate visual intrigue with the three equations colliding into a mathematical puzzle.
  - Pacing rules: Enforces visual changes every 2.5–3.5 seconds to retain viewer immersion.

#### 2.2 REMOTION SKILLS (`remotion-dev/skills`)
- **Core Philosophy:** Deterministic, frame-perfect React video rendering with full control over audio waveforms, Spring-physics, and interpolated layouts.
- **Key Discovered Skills:**
  - `remotion-best-practices`: Single source of truth for composition hierarchy, avoiding state-drift, memoization, and layout isolation.
  - `remotion-markup`: Best practices for React DOM transforms, `<Composition />`, `<Sequence />`, `<Series />`, absolute fill styling, and `@remotion/shapes`.
  - `remotion-render`: Headless CLI rendering flags, hardware acceleration, multi-threading, concurrency, and memory management.
  - `remotion-captions`: Precise frame-locked typography and speech synchronization.
- **Applicability to Project Gauss:**
  - **The definitive execution framework**. All matrix manipulations, row highlights, pivot animations, and Gauss character reactivity are engineered as Remotion React components.

#### 2.3 HYPERFRAMES (`heygen-com/hyperframes`)
- **Core Philosophy:** Open-source framework turning HTML, CSS, JavaScript, and seekable animations into deterministic MP4 videos without requiring heavy frameworks.
- **Key Discovered Skills:**
  - `hyperframes-cli`, `hyperframes-registry`, `media-use`, `remotion-to-hyperframes`, `style-sampling`.
- **Evaluation & Engine Decision:**
  - While HyperFrames offers rapid HTML prototyping, Remotion provides strictly typed TypeScript component hierarchies, native SVG matrix bracket math, deep `@remotion/shapes` primitives, and an established React ecosystem needed for our custom interactive Gauss character system.
  - HyperFrames is utilized for motion curve inspiration and modular CSS grid layout patterns.

#### 2.4 OPENMONTAGE (`OpenMontageInc/OpenMontage`)
- **Core Philosophy:** End-to-end agentic video production studio dividing production into specialized director agents (Proposal, Script, Scene, Asset, Compose, Edit, Publish).
- **Key Discovered Pipelines & Skills:**
  - `skills/pipelines/explainer/`: Detailed breakdowns of idea -> script -> storyboard -> asset -> composition -> QA.
  - `skills/pipelines/character-animation/`: Rig planning, pose sequencing, expression switching, and synchronizing character reactions to narrative beats.
  - `skills/core/remotion.md` & `skills/core/subtitle-sync.md`: Practical guidelines for aligning voice timestamps to visual milestones.
- **Licensing Constraint (AGPLv3):**
  - OpenMontage is licensed under AGPLv3. To preserve total licensing cleanliness and academic distribution freedom for Project Gauss, **zero OpenMontage code is copied or linked**. We adopt its proven architectural methodology and QA checklists purely as design principles.

#### 2.5 LEMO-OPUSCAR (`lemomo-ai/lemo-opuscar`)
- **Core Philosophy:** Generative filmmaking through strict aesthetic rulebooks. 100+ defined cinematic styles with exact constraints on shapes, color roles, type hierarchy, and camera movement.
- **Key Discovered Styles & References:**
  - `styles/bauhaus-shapes/STYLE.md`: "Shapes are amounts. Circle = what grows or moves; square = what stays or weighs; triangle = slope, time, pivot. The grid is visible."
  - `styles/dataviz/STYLE.md`: "The chart is the film. Honesty beats drama. Color encodes one thing: value."
  - `styles/hardcore-info/` & `styles/flat-space-explainer/`: Editorial Swiss grid layouts, oversized grotesk numbers, razor-sharp alignment.
- **Applicability to Project Gauss:**
  - Directly anchors our **Chromatic Swiss Visual Identity**:
    1. Grid lines visible during matrix restructuring.
    2. Pivots treated as foundational geometric anchors (Lemon Yellow highlight, Cobalt Blue structure).
    3. Operation callouts styled as bold editorial brackets with high typographic contrast.
